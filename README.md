# Scroll Studio showcase

Sample sites built with [Scroll Studio](https://github.com/Okohedeki/scroll-studio), an open-source engine that turns one YAML file into a scroll-driven website.

Live: https://okohedeki.github.io/scroll-studio-showcase/

This repo only holds the built output, generated with `studio publish`. Each site's source spec is in the engine repo under `examples/`. All sites are concept sites.

The showcase is organised by release and by scene: **New in 1.5** (six art-directed landing pages, each built with no GPU from the raw stills in its spec: [Kitewell](https://okohedeki.github.io/scroll-studio-showcase/kitewell/) in risograph with drifting clouds, [Gloamery](https://okohedeki.github.io/scroll-studio-showcase/gloamery/) in gouache with the pointer as a lamp, [Tarnhollow](https://okohedeki.github.io/scroll-studio-showcase/tarnhollow/) in watercolour under a colour lens, [Tidelow](https://okohedeki.github.io/scroll-studio-showcase/tidelow/) as a halftone on indigo, [Millrace](https://okohedeki.github.io/scroll-studio-showcase/millrace/) in ink with captions placed on the grid, and [Bramblecote](https://okohedeki.github.io/scroll-studio-showcase/bramblecote/), a plain page remade with `studio remake` and painted in gouache; plus [the 30-second 1.5 film](https://okohedeki.github.io/scroll-studio-showcase/recordings/1.5.mp4)), **In 1.4** (the one-take page, cinemagraphs, light as the scroll, inside the product, miniature worlds, film cuts, type in the world, direction boards, six new styles; shown as recordings) and **Every scene** (sixteen live sites, one per kind of scroll, plus [Halcyon in thirty-two styles](https://okohedeki.github.io/scroll-studio-showcase/halcyon/looks/)). Concepts (unofficial redesigns of real products, not affiliated with the companies shown: [OpenCode](https://okohedeki.github.io/scroll-studio-showcase/opencode/) and [CircuitHub](https://okohedeki.github.io/scroll-studio-showcase/circuithub/)) are in the [concepts gallery](https://okohedeki.github.io/scroll-studio-showcase/concepts/).
