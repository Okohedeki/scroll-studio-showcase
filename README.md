# Scroll Studio showcase

Sample sites built with [Scroll Studio](https://github.com/Okohedeki/scroll-studio), an open-source engine that turns one YAML file into a scroll-driven website.

Live: https://okohedeki.github.io/scroll-studio-showcase/

This repo only holds the built output, generated with `studio publish`. Each site's source spec is in the engine repo under `examples/`. All sites are concept sites.

The showcase is organised by scene: **New in 1.4** (the one-take page, cinemagraphs, light as the scroll, inside the product, miniature worlds, film cuts, type in the world, direction boards, six new styles; shown as recordings) and **Every scene** (sixteen live sites, one per kind of scroll, plus [Halcyon in thirty-two styles](https://okohedeki.github.io/scroll-studio-showcase/halcyon/looks/)). Concepts (unofficial redesigns of real products) are in the [concepts gallery](https://okohedeki.github.io/scroll-studio-showcase/concepts/).
