# Scroll Studio showcase

Sample sites built with [Scroll Studio](https://github.com/Okohedeki/scroll-studio), an open-source engine that turns one YAML file into a scroll-driven website.

Live: https://okohedeki.github.io/scroll-studio-showcase/

This repo only holds the built output, generated with `studio publish`. Each site's source spec is in the engine repo under `examples/`. All sites are concept sites.

New in v3: [Stillwater](https://okohedeki.github.io/scroll-studio-showcase/one-take/) (One Take with a real 3D product), [Hollis House](https://okohedeki.github.io/scroll-studio-showcase/hollis-house/) (a Gaussian-splat walkthrough), [Pelorus](https://okohedeki.github.io/scroll-studio-showcase/pelorus/) (figures read from the data) and [Halcyon in twenty styles](https://okohedeki.github.io/scroll-studio-showcase/halcyon/looks/).
