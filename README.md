# Scroll Studio showcase

Sample sites built with [Scroll Studio](https://github.com/Okohedeki/scroll-studio), an open-source engine that turns one YAML file into a scroll-driven website.

Live: https://okohedeki.github.io/scroll-studio-showcase/

This repo only holds the built output, generated with `studio publish`. Each site's source spec is in the engine repo under `examples/`. All sites are concept sites.
