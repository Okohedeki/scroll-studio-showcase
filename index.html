How it works

One spec in, one static site out.

01 · Describe

Write site.yaml

Sections, copy, theme and inputs: files, URLs, or images generated locally from a prompt. Or ask Claude to write it.

02 · Build

studio build

Each scene type renders what it needs: Blender, LTX-2.3, depth maps, vector traces, data. Cached stage by stage.

03 · Ship

Upload dist/

Plain HTML, CSS and JS with the media. Host it anywhere; no server, no API keys.
