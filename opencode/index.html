Questions

What is OpenCode?

An open source agent that helps you write and run code with any AI model. It's available as a terminal interface, desktop app or IDE extension.

Do I need extra AI subscriptions?

Not necessarily. OpenCode comes with a set of free models you can use without an account, and works with all the popular providers, including local models.

Can I use my existing AI subscriptions?

Yes: Claude Pro/Max, ChatGPT Plus/Pro or GitHub Copilot.

Can I only use it in the terminal?

No. OpenCode is also an app for your desktop and the web.

How much does it cost?

OpenCode is free to use and comes with free models. Other providers may cost extra.

What about data and privacy?

Your data is only stored when you use the free models or create sharable links.

Is it open source?

Yes, fully: the source is on GitHub under the MIT License.
